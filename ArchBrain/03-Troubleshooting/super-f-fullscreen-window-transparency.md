# Super + F Fullscreen Window Transparency

Documentation of the issue where pressing `Super + F` (maximized/bordered fullscreen) or `F11` caused windows to become 100% transparent.

---

## Symptoms & Root Cause

### 1. Symptoms
- Pressing `Super + F` (or `F11`) on any focused window immediately turned the window completely transparent/invisible.
- Normal, tiled, or floating windows had normal visibility.

### 2. Root Cause
1. In `~/.config/hypr/hyprland/rules.lua`, non-fullscreen windows had an explicit opacity override:
   ```lua
   hl.window_rule({ match = { fullscreen = false }, opacity = vars.windowOpacity .. " override" })
   ```
2. In `~/.config/hypr/hyprland-gui.lua` (generated by HyprMod GUI settings), global decoration opacity had been saved as:
   ```lua
   decoration = {
       active_opacity = 0.0,
       inactive_opacity = 0.15,
   }
   ```
3. When a window was not fullscreen (`fullscreen: false`), rule (1) overrode `active_opacity` to `0.95`.
4. When pressing `Super + F` or `F11`, the window entered fullscreen/maximized mode (`fullscreen: true`), causing rule (1) to stop matching. Hyprland fell back to global `decoration.active_opacity = 0.0`, instantly rendering the window completely transparent.

---

## Resolution
1. Corrected `active_opacity = 1.0` and `inactive_opacity = 1.0` in:
   - `~/.config/hypr/hyprland-gui.lua`
   - `~/.config/hypr/hyprmod/profiles/016363015e2f/hyprland-gui.lua`
   - `~/dotfiles/.config/hypr/hyprland-gui.lua`
2. Executed `hyprctl reload` to apply settings dynamically.
