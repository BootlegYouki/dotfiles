# Installed Desktop Applications & Software Registry

## Core Desktop Environment
- **Compositor**: Hyprland (`v0.56.2`) via UWSM
- **Desktop Shell**: Caelestia Shell (`v2.2.0`) & Caelestia CLI (`v1.1.2`)
- **Toolkit**: QuickShell (`quickshell-git 0.3.0`)
- **Terminal**: Ghostty (`v1.3.1`)
- **File Manager**: Thunar (`v4.20.9`)
- **System Monitors**: `btop`, `rclone`

## Web Browsers & Development
- **Web Browser**: Brave Browser (`brave-bin`), Firefox
- **Version Control**: Git (`git 2.55.0`), GitHub CLI (`github-cli 2.97.0`), Git LFS (`git-lfs 3.7.1`)
- **GitHub Projects Location**: `~/github/`
- **Text Editors**: Micro, Zed
- **AI CLI**: Antigravity CLI (`agy 1.1.11`)

## Gaming & System Utilities
- **Gaming Platform**: Steam & Proton-CachyOS
- **Bluetooth**: Blueman (`blueman-manager`)
- **Wi-Fi / Network**: NM Connection Editor (`nm-connection-editor`)
- **Credential Storage**: GNOME Keyring (`gnome-keyring`)
- **Icon Theme**: Papirus (`papirus-icon-theme`)
